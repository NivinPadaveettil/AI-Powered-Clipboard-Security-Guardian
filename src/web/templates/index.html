Security & Privacy Architecture

Zero-cloud transmission, local model execution, and privacy guarantees

🔒 100% Local Inference

All clipboard classification is run using an embedded local DistilBERT Transformer. Your data never leaves your computer.

🛡️ Zero Raw-Text Persistence

The SQLite database stores ONLY classification metadata (risk level, score, timestamp, category). The raw text is never written to disk.

⚡ Automated Clipboard Clearing

Sensitive data copied to the OS clipboard is automatically overwritten after a configurable timeout to prevent unauthorized paste leaks.
